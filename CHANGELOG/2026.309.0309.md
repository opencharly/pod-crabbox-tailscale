# 2026.309.0309 — feat(image): add the tailscale lease image pod-crabbox-tailscale

## Summary

Adds `pod-crabbox-tailscale`: the tailnet-joinable lease image for the Crabbox `containerd` provider, one of the `pod-crabbox-<variant>` images tracked by opencharly/opencharly#869 (W5.2). It is the pinned `opencharly/pod-crabbox` lease contract plus the `tailscale` CLI, the `tailscaled` daemon, an enabled `tailscaled.service`, and the `TS_DEBUG_DISABLE_UDP_GSO=1` drop-in the libkrun TSI path needs.

- **`charly.yml`** — the image: `import: crabbox: @github.com/opencharly/pod-crabbox:v2026.307.1828` with `base: crabbox.pod-crabbox`, `distro: [cachyos, arch]`, and `user: root` with the inherited direct-mode `sshd -D` entrypoint.
- **`candy/tailscale-lease/charly.yml`** — the Arch `tailscale` package (`extra/tailscale 1.104.2-1`; its file list carries `/usr/bin/tailscale`, `/usr/bin/tailscaled` and `/usr/lib/systemd/system/tailscaled.service`), the unit enabled at boot, and `/etc/systemd/system/tailscaled.service.d/10-tsi-gso.conf` setting `Environment=TS_DEBUG_DISABLE_UDP_GSO=1` (CONTAINERD-IMAGES.md §2, LIBKRUN.md §7). The daemon binary is asserted separately from the CLI: a lease whose consumer `exec`s `/usr/bin/tailscaled` fails before login when an image ships only the CLI.
- **Nine deterministic `check:` steps** — the CLI binary, the daemon binary, `tailscale version` (offline), `pacman -Q tailscale`, the drop-in line, the enabled unit link, and the inherited lease contract (sshd/bootstrap/readiness, uid-1000 `crabbox`, the 2222 SSH drop-in).
- **`.github/workflows/image.yml`** — the thin caller of the org reusable `image-build.yml`, pinned by commit (`@bd1e195cadfce40e09719d99a16f7353e1aa27bd`): `pull_request`/`workflow_dispatch` build only (a `ci-<sha>` tag, publishing nothing); a successful `tag-on-merge` completion publishes the newest `v*` git tag as the image tag.
- **`README.md`, `AGENTS.md`, `CHANGELOG/.gitkeep`, `.gitignore`** — repo overview, repo guidance, the history directory, and generated-file ignores.
